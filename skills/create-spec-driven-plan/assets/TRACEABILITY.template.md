## Traceability rules

1. preserve candidate origin (`CR-*`) and authoritative source (`SRC-*`);
2. assign a stable `REQ-*` ID without recycling it;
3. map every active requirement to at least one task;
4. map every task to at least one requirement;
5. define an observable oracle and applicable security control;
6. update evidence and state without deleting historical origin.
