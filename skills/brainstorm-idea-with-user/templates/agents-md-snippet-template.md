## AI workflow

Este projeto utiliza o contrato `planning-delegation/v2`.

Leia primeiro:

1. `docs/ai/<project-slug>/PROGRESS.md`
2. o documento ativo apontado por `active_artifact`
3. o handoff da etapa atual
4. os contratos referenciados pela tarefa

`PROGRESS.md` é o único ponteiro operacional.

Não use esta seção como fonte de status.
Não implemente com base em conversas históricas quando houver spec validada.
Não execute uma skill diferente da indicada em `next_skill`.
